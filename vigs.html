PROJECT INFO

◈ Arduino Programming

The Visual Impaired Guide System is a smart assistive system for visually impaired individuals using ultrasonic sensors, RFID, and motion sensing. It provides obstacle detection, location identification, audio guidance, and fall detection for safe navigation. Sustainability Development Goals mapped are: SDG 3 (Good Health and Well-Being), SDG 9(Industry, Innovation and Infrastructure) and SDG 10(Reduced Inequalities)

Problem Statement: To design and develop a wearable smart guidance system for visually impaired individuals that enables safe navigation through obstacle detection, motion sensing, and RFID-based location identification with real-time audio feedback.

Objective :
To detect obstacles and provide audio alerts for safe navigation.
To identify locations using RFID-based voice guidance.
To detect motion or falls for enhanced user safety.

Result:
Obstacle detection accuracy above 95% within 50–100 cm.
RFID announcements with latency below 300 ms.
4+ hours of continuous operation on a single charge.
Successful browser monitoring using Web Serial API.

Conclusion: The prototype provides a reliable, low-cost, and user-friendly navigation aid using ultrasonic and RFID-based guidance with web audio feedback. Its modular design also supporats future upgrades like GPS and AI integration.

◈ PCB Designing

As a part of our mini project, we designed and developed a custom PCB using the knowledge and techniques learned during our second workshop under the PCB Designing trade. We applied the practical methods taught in the workshop, such as circuit layout planning, component placement, track routing, soldering, and PCB fabrication, to create an efficient and compact circuit for our system.
