# VIGS – Visual Impaired Guide System

## 📌 About the Project

**VIGS (Visual Impaired Guide System)** is a smart assistive system designed to help visually impaired individuals navigate their surroundings more safely and independently.

This repository contains the **web dashboard developed for the VIGS project**. The website provides a user-friendly interface for monitoring sensor data received from the hardware system and displaying the information through the dashboard.

The website also uses **Node.js** for communication and connectivity between the hardware nodes and the web interface.

## 🌐 Website Features

* 📊 **Sensor Dashboard** – Displays data received from the VIGS hardware.
* 📡 **Real-Time Monitoring** – Monitors sensor information through the website.
* 🔌 **Hardware Connectivity** – Uses Node.js to establish communication with the connected hardware node.
* 📍 **System Status** – Displays relevant information generated by the VIGS system.
* 💻 **Interactive Dashboard** – Provides a simple and user-friendly interface for monitoring the system.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone <your-repository-link>
```

### 2. Install Node.js

Make sure **Node.js and npm** are installed on your computer.

Check the installation using:

```bash
node -v
npm -v
```

### 3. Install Required Dependencies

The required Node.js packages are listed in `package.json`.

Run:

```bash
npm install
```

This automatically downloads and installs all required dependencies into the `node_modules` folder.

### 4. Start the Node.js Server

Run the Node.js server using:

```bash
node server.js
```

### 5. Open the Website

Open the website in your browser and connect the required VIGS hardware/node.

The dashboard can then be used to monitor the sensor data received from the hardware.

## 🎯 Purpose

The main purpose of this website is to provide a **web-based monitoring interface for the VIGS hardware system**.

It allows sensor readings and system information to be viewed through a centralized dashboard, making it easier to monitor and test the VIGS prototype.
